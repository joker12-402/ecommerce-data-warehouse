# 项目概览

## 1. 项目背景

在电商平台中，用户会产生大量行为数据，例如浏览商品、收藏商品、加入购物车、下单购买等。

这些用户行为数据可以帮助业务方分析：

- 平台整体访问情况
- 用户购买转化情况
- 商品热度排行
- 用户行为路径
- 营销活动效果

本项目基于电商用户行为场景，使用 MySQL 构建一个轻量级的数据仓库项目，模拟从原始数据采集到应用层指标产出的完整过程。

---

## 2. 项目目标

本项目主要目标包括：

1. 搭建一个本地 MySQL 数据仓库项目
2. 理解 ODS、DWD、DWS、ADS 四层数仓结构
3. 使用 SQL 完成用户行为数据清洗和汇总
4. 计算电商常见业务指标
5. 将 SQL 脚本整理成可复现、可维护的项目结构

---

## 3. 业务场景

本项目模拟的业务对象是电商平台用户行为日志。

每条用户行为记录包含：

| 字段 | 含义 |
| --- | --- |
| user_id | 用户 ID |
| item_id | 商品 ID |
| category_id | 商品类目 ID |
| behavior_type | 用户行为类型 |
| behavior_time | 行为发生时间 |

其中，用户行为类型包括：

| 行为类型 | 含义 |
| --- | --- |
| pv | 浏览商品 |
| fav | 收藏商品 |
| cart | 加入购物车 |
| buy | 购买商品 |

---

## 4. 核心分析问题

本项目主要回答以下业务问题：

### 4.1 每日整体经营情况如何？

通过 ADS 层的每日经营概览表，可以分析：

- 每日浏览次数
- 每日访问用户数
- 每日加购次数
- 每日收藏次数
- 每日购买次数
- 每日购买用户数
- 每日购买转化率
- 每日人均购买次数

---

### 4.2 哪些商品更受用户欢迎？

通过 ADS 层的每日热门商品排行表，可以分析：

- 每日商品浏览热度
- 每日商品购买情况
- 每日 Top 商品排名

---

## 5. 项目产出

本项目最终产出包括：

| 类型 | 内容 |
| --- | --- |
| SQL 脚本 | 建库、建表、数据清洗、指标汇总 |
| 数仓表 | ODS、DWD、DWS、ADS 各层表 |
| 业务指标 | PV、UV、加购、收藏、购买、转化率等 |
| 项目文档 | README 和 docs 说明文档 |
| 可复现流程 | 可通过终端一键按顺序执行 SQL 脚本 |

---

## 6. 项目适用人群

本项目适合：

- 数据分析初学者
- 数据仓库初学者
- SQL 学习者
- 想准备数据开发、数据分析项目经历的人
- 想从 MySQL 过渡到 Hive、Spark 的学习者

---

## 7. 后续扩展方向

后续可以在当前项目基础上继续扩展：

- 增加用户维表、商品维表、类目维表
- 增加 GMV、客单价、复购率、留存率等指标
- 引入 Python 脚本自动执行 SQL
- 使用 Airflow 编排每日任务
- 将 MySQL 数仓迁移到 Hive 或 Spark
- 使用 BI 工具进行可视化展示
